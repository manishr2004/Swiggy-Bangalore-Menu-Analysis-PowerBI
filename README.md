# Swiggy-Bangalore-Menu-Analysis-PowerBI
# 🍽️ Swiggy Bangalore Insights Dashboard

### 📊 Power BI Project — Restaurant & Cuisine Analysis

This dashboard analyzes restaurant data from **Swiggy (Bangalore)** to uncover insights about cuisine trends, pricing, customer ratings, and restaurant performance across various locations in the city.

---

## 🧾 **Project Overview**

- **Objective:**  
  To visualize and explore Swiggy’s Bangalore menu dataset — focusing on restaurant variety, dish pricing, and customer preferences.

- **Dataset Used:**  
  `swiggy_all_menus_bangalore.xlsx`  
  *(Contains ~24,800 rows with restaurant, location, category, dish, price, and rating details.)*

- **Tool:**  
  🟡 **Power BI**

---

## 📈 **Key Insights Displayed**

| Insight | Description |
|----------|-------------|
| ⭐ **Average Rating** | Average customer satisfaction across all dishes |
| 💰 **Average Price (INR)** | Mean dish price across Bangalore |
| 🏪 **Total Restaurants** | Count of unique restaurant outlets |
| 📍 **Locations Covered** | Number of areas represented in dataset |
| 🍱 **Total Menu Items** | Count of all listed dishes |
| 🍔 **Top 5 Restaurants** | Restaurants offering the most dishes |
| 🧁 **Most Ordered Dishes** | Popular dishes by count |
| 🗺️ **Areas with Most Restaurants** | Top zones in Bangalore for food variety |
| 📊 **Dish Price vs. Rating** | Relation between pricing and customer rating trends |

---

## 🧩 **Dashboard Features**

- Interactive filters for **Restaurant Name**, **Location**, and **Cuisine Category**  
- Dynamic KPIs and charts auto-update with slicer selections  
- Visual breakdown of:
  - Top 5 restaurants by menu size
  - Most ordered dishes
  - Area-wise restaurant distribution
- Custom **Swiggy-themed color palette** and branding
